# kosmos_auth - Clés Config & Theme

Package: **kosmos_auth** (v2.0.0)

---

## Config Keys

Ce package ne définit pas de PackageConfig propre.
L'authentification est configurée via `SkeletonAuthentificationConfig` dans le package `skeleton`.

---

## Theme Keys

Ce package ne définit pas de thèmes propres.

---

## Usage

```dart
// L'auth est intégré via skeleton
import 'package:kosmos_auth/kosmos_auth.dart';

// Controllers disponibles:
// - AuthController (login, logout, register)
// - TiersAuthController (Apple, Google sign-in)
```
