stat_catalog

models/stat_catalog library

Classes

StatDef
Définition d'une statistique paramétrable (écran « Paramétrez les statistiques »).

Enums

StatCategory
Thème d'une statistique (9 thèmes du client, dans l'ordre d'affichage) : regroupe les stats en cartes dans l'écran « Match en cours » (maquette Figma) et titre les blocs des bilans.

Constants

kStatCatalog → const List<StatDef>
Catalogue des 42 statistiques (37 saisies + 5 calculées), dans l'ordre des 9 thèmes du client. Les clés sont persistées (playerStats, enabledStatKeys) : n'en renommer aucune, seuls libellés et thèmes changent.
kStatNoValue → const String
Valeur affichée quand une statistique n'a pas de sens (aucune passe pour un pourcentage) ou pas de valeur (2e mi-temps non jouée). Tiret cadratin : Poppins, police de l'app et du PDF collectif, le dessine ; le Helvetica par défaut des autres PDF ne le dessinerait pas (aucun ne l'affiche).

Properties

kStatToggles → List<StatDef>
Les 37 statistiques saisies : seules à être des bascules du paramétrage (les 5 calculées apparaissent d'elles-mêmes, voir enabledStatsInCatalogOrder).
final

Functions

defaultEnabledStatKeys() → List<String>
Clés activées par défaut.
enabledStatsInCatalogOrder(Iterable<String> keys) → List<StatDef>
Statistiques suivies d'après keys, dans l'ordre du catalogue (et non celui du stockage : enabledStatKeys suit l'ordre de clic de l'écran de paramétrage, une stat activée après coup partirait en fin de liste). Une stat calculée est suivie quand TOUTES ses composantes le sont, que sa propre clé figure ou non dans keys (anciens matchs). Les clés inconnues du catalogue sont ignorées. Aucun filtre bilanOnly : chaque lecteur applique le sien.
formatPercent(int part, int whole) → String
Pourcentage part / whole au centième, demi vers le haut, virgule et deux décimales toujours (« 75,00 % », espace insécable avant « % ») ; kStatNoValue quand whole est nul. Arithmétique entière : toStringAsFixed se trompe sur les demis (23/160 donne 14,37).
formatStat(Map<String, int>? raw, StatDef s) → String
Texte affiché pour la stat s d'après les compteurs bruts raw : le nombre (total calculé compris, voir readStat) ou, pour la stat en % (bilanOnly, « Réussite de passes »), le pourcentage de passes réussies. SEUL endroit qui assemble ce %, pour le bilan collectif comme pour le tableau et le PDF individuels.
maxStatValue(String key) → int
Valeur maximale saisissable en direct pour key, par match et par joueur. Un joueur ne peut prendre qu'un seul carton rouge, et au plus deux jaunes (au 2e, l'arbitre sort le rouge) ; les autres statistiques gardent le plafond générique.
readStat(Map<String, int>? raw, String key) → int
Valeur de key dans raw (compteurs bruts clé → valeur d'un joueur, d'une équipe ou d'un cumul). SEUL endroit qui calcule un total : il se dérive de ses composantes, une valeur qui traînerait sous sa clé (anciens matchs) est ignorée. Pour une période ou un cumul, sommer les compteurs bruts PUIS appeler ceci, jamais l'inverse.
toggleKeys(Iterable<String> keys) → List<String>
Clés de keys qui sont des bascules du paramétrage : écarte les stats calculées et les clés inconnues que d'anciens matchs portent encore (enabledStatKeys d'avant les stats calculées). C'est ce qui se compte dans « X / 37 » et dans les pastilles « N statistiques ».
