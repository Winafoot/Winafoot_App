matchId property

String? get matchId

Identifiant du match auquel mène le bouton d'action, ou null si la notification n'en désigne aucun. Le contrôle du type évite d'interpréter comme un match l'entityId d'une notification d'une autre nature.

Implementation

String? get matchId {
  if (type != kMatchFinishedNotificationType) return null;
  final Object? id = metadata?['entityId'];
  return id is String && id.isNotEmpty ? id : null;
}
