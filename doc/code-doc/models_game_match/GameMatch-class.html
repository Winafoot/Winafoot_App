GameMatch

GameMatch class

Un match : construit dans l'assistant « Coup d'envoi », puis joué.

Porte l'adversaire et le maillot porté, la ou les compositions, les statistiques activées, le statut, le score, le temps de jeu, la mi-temps et les statistiques par joueur (voir README, section Fonctionnement).
