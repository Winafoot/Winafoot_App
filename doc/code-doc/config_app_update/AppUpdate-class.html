AppUpdate

AppUpdate class abstract final

Mise à jour forcée, pilotée par app_config/metadata :

minBuild: { android: <int>, ios: <int> }
storeUrl: { android: <string>, ios: <string> }

Une version dont le numéro de build est inférieur à minBuild de sa plateforme affiche l'écran bloquant UpdateRequiredPage, avec un bouton vers storeUrl. Champ absent, mal formé ou plateforme non renseignée : aucun blocage.
