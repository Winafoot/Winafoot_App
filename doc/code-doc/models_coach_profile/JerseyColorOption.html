JerseyColorOption

JerseyColorOption enum

Couleur de maillot (libellé + visuel shirt-*.png dans assets/images + couleur représentative pour les teintes, ex. écusson d'équipe). Chaque visuel est peint à cette teinte (le blanc a un corps #F7F7F7 cerné de gris, sinon il disparaît sur fond blanc) : à recolorer ensemble, PNG et constante.
