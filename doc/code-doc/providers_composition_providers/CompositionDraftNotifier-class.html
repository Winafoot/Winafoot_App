setNumber(String playerId, int number, {required bool isSubstitute}) → void
Attribue number à playerId depuis le pool titulaire ou remplaçant (design « Attribuer les numéros » / « Numéros des remplaçants », deux grilles séparées : cf. Figma 1:421 / 1:424). Un numéro est unique dans TOUTE l'équipe : il est retiré du joueur qui le portait éventuellement, quel que soit son pool (un titulaire et un remplaçant ne peuvent pas partager le même numéro). Le statut remplaçant de playerId suit automatiquement le pool choisi — c'est le pool qui fait foi, il n'y a plus de bascule manuelle indépendante : le bloc Remplaçants liste tous les joueurs ayant un numéro de remplaçant attribué.
setSubNumbers(Set<int> numbers) → void
Numéros réservés aux remplaçants, choisis librement parmi les 36 de la grille — y compris ceux que la grille titulaire propose aussi : c'est un choix du coach, et l'unicité reste garantie à l'attribution par setNumber, qui retire le numéro à celui qui le portait.
