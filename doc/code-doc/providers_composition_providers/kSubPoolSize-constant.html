kSubPoolSize top-level constant

int const kSubPoolSize

Taille du pool de numéros remplaçants (grille bleue « Numéros des remplaçants », design 1:424). Ce pool commence APRÈS celui des titulaires (12 à 16 dans un 11 contre 11) : les numéros étant uniques dans toute l'équipe, des pools qui se recouvrent rendraient tout numéro de remplaçant indisponible dès que les titulaires occupent 1 à 5.
