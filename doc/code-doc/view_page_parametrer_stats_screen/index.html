ParametrerStatsScreen
Écran « Paramétrez les statistiques » : active/désactive les statistiques suivies pendant le match (3 colonnes de bascules, un titre par thème). Les 5 statistiques calculées (totaux, réussite de passes) n'y figurent pas : elles s'affichent d'elles-mêmes quand toutes leurs composantes sont suivies. « Valider » enregistre la sélection sur le match et revient au hub.
