Static Methods

abandonMatch(String id) → Future<void>
Marque un match comme abandonné (quitté sans finaliser). Le résultat n'est pas enregistré : le match n'apparaît pas dans l'historique, filtré sur finished (cf. watchFinishedMatches).
deleteMatch(String id) → Future<void>
Supprime définitivement un match et ses statistiques (historique « Statistiques Matchs »).
finishedPayload(LiveMatch live) → Map<String, dynamic>
Champs du résultat d'un match terminé, hors finishedAt (horodaté par le serveur). Écrits par TOUS les chemins de fin de match (écran de direct en 2e mi-temps, écran de coupure « Fin du match »).
finishMatch(String id, LiveMatch live) → Future<void>
Enregistre le résultat d'un match terminé (score, statistiques par joueur, durée) sur le document existant.
getMatch(String id) → Future<GameMatch?>
Lit un match par son identifiant. null si le document n'existe plus (match supprimé depuis l'historique).
matchFinishedPayload({required String uid, required String matchId, required String title, required String body, required String ctaLabel}) → Map<String, dynamic>
Charge utile du callable addNotification pour « Match terminé ».
saveDraft(GameMatch match) → Future<String>
Crée (si match.id est nul) ou met à jour le brouillon du match courant. Retourne l'identifiant du document.
watchFinishedMatches() → Stream<List<GameMatch>>
Flux des _historyLimit derniers matchs terminés (les plus récents d'abord). Le tri est fait par Firestore sur finishedAt : les brouillons et les matchs abandonnés n'ont pas ce champ et sont donc absents du résultat, ce qui évite l'index composite (where + orderBy).
