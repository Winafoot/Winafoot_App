watchFinishedMatches static method

Stream<List<GameMatch>> watchFinishedMatches()

Flux des _historyLimit derniers matchs terminés (les plus récents d'abord). Le tri est fait par Firestore sur finishedAt : les brouillons et les matchs abandonnés n'ont pas ce champ et sont donc absents du résultat, ce qui évite l'index composite (where + orderBy).

Implementation

static Stream<List<GameMatch>> watchFinishedMatches() {
  return _col()
      .orderBy('finishedAt', descending: true)
      .limit(_historyLimit)
      .snapshots()
      .map(
        (QuerySnapshot<Map<String, dynamic>> snap) => snap.docs
            .map(
              (QueryDocumentSnapshot<Map<String, dynamic>> d) =>
                  GameMatch.fromDoc(d.id, d.data()),
            )
            .where((GameMatch m) => m.status == MatchStatus.finished)
            .toList(growable: false),
      );
}
