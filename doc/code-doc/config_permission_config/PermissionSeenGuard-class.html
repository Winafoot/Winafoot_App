PermissionSeenGuard

PermissionSeenGuard class

Redirige vers l'écran de permission tant qu'il n'a pas été vu sur cet appareil.

Écrit ici plutôt que d'utiliser le PermissionGuard du package : celui-ci enchaîne un get() Firestore sans catchError ni timeout, et si la lecture échoue (démarrage hors-ligne avec cache vide, App Check refusé) le resolver n'est jamais complété — la navigation reste pendante pour toute la session, sans reprise possible. Le drapeau local suffit : une permission de notification est de toute façon une donnée par appareil.
