Functions

bilanIndividuelContent(GameMatch match, Map<String, Player> byId, MatchPeriod period) → List<Widget>
Contenu du bilan individuel d'une period : une tranche de colonnes par page, chacune avec « Joueur » et « N° » répétés. Les stats suivies sont celles de la période, calculées et % compris ; 2e mi-temps non jouée : les colonnes du match, chaque cellule à « — ».
bilanIndividuelRows(LiveMatch live, Map<String, Player> byId) → List<({int? number, Player player})>
Lignes du bilan individuel : titulaires par poste puis remplaçants, avec le numéro de la composition — exactement celles de l'écran (MatchStatsBoard), via LiveMatch.
buildBilanCollectifDocument({required GameMatch match, required MatchPeriod period, required String ownTeam, required String opponent, ThemeData? theme}) → Document
Construit le PDF du « Bilan collectif » (sans le partager) : A4 portrait, la seule period affichée à l'écran (1ère mi-temps, 2ème mi-temps ou Total match), au format du document du client. Si elle ne tient pas sur une page, elle déborde sur la suivante, en-tête répété. theme fournit la police (Helvetica à défaut).
buildBilanIndividuelDocument({required GameMatch match, required Map<String, Player> byId, required String title, MatchPeriod period = MatchPeriod.total, ThemeData? theme}) → Document
Construit le PDF du « Bilan individuel » d'une period (sans le partager). theme fournit la police (Helvetica à défaut : ni « — » ni « ’ »).
exportBilanCollectifPdf({required GameMatch match, required MatchPeriod period, required String ownTeam, required String opponent}) → Future<void>
Exporte le « Bilan collectif » de la period affichée : les statistiques suivies par thème (voir buildBilanCollectifDocument).
exportBilanIndividuelPdf({required GameMatch match, required Map<String, Player> byId, required String title, MatchPeriod period = MatchPeriod.total}) → Future<void>
Exporte le « Bilan individuel » d'une period : une ligne par joueur (titulaires puis remplaçants), les statistiques suivies réparties sur plusieurs pages.
poppinsPdfTheme() → Future<ThemeData>
Police des PDF de bilan : Poppins (celle de l'app, déjà embarquée). Le Helvetica par défaut ne dessine que le latin-1 : un nom d'équipe ou de joueur avec « ’ » ou « Œ », ou « — », y sortirait en carré vide.
splitStatsByPage(List<StatDef> stats, {int maxPerPage = kStatsPerPage}) → List<List<StatDef>>
Découpe stats (dans l'ordre du catalogue) en pages de maxPerPage colonnes au plus. Les catégories consécutives se regroupent sur une même page ; une catégorie qui ne rentre pas dans la place restante ouvre la page suivante, sauf si elle dépasse à elle seule maxPerPage : elle est alors coupée (et remplit la page en cours).
