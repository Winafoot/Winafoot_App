maxSquadSizeProvider top-level property

FutureProvider<int> maxSquadSizeProvider
final

Plafond d'effectif effectif : celui du format du club (teamFormat, 5 → 9, 8 → 14, 11 → 20) s'il est connu, sinon app_config/config.max_players (repli 20 : jamais le plafond d'un petit format).

Exposé comme provider pour que l'INTERFACE dise la même chose que l'enforcement : les libellés « X sur N joueurs » et les boutons désactivés s'alignaient jusqu'ici sur la constante de repli, si bien qu'un plafond différent appliqué par les règles Firestore n'aurait jamais été affiché. Dérivé du profil, lui-même rattaché à authUidProvider : le plafond suit le compte connecté, sans cache propre.

Utiliser ref.watch(maxSquadSizeProvider).valueOrNull ?? kMaxSquadSize : pendant le chargement, mieux vaut le repli historique qu'un « X sur 0 ».

Implementation

final maxSquadSizeProvider = FutureProvider<int>((ref) async {
  final PlayerCount? format = ref.watch(teamFormatProvider);
  return format?.maxSquadSize ?? await PlayerRepository.configMaxSquadSize();
});
