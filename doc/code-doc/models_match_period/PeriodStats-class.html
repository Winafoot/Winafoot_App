PeriodStats class

Statistiques d'un match sur une MatchPeriod. Un état sans valeurs (PeriodStatus.unavailable, PeriodStatus.notPlayed) est explicite : il ne se confond ni avec « aucune stat saisie » ni avec un match à zéro.
