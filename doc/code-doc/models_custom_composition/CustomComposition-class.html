CustomComposition

CustomComposition class

Composition tactique personnalisée, créée par le coach et réutilisable entre les matchs. Persistée dans users/{uid}/compositions.

Contrairement à une composition standard (constante de l'app, cf. formation.dart), elle porte un nom libre, un libellé de schéma libre et des emplacements de maillots positionnés à la main sur le terrain.
