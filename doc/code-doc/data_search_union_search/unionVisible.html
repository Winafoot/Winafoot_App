Résultats visibles d'une barre de recherche : filtre local actuel UNION les éléments dont l'identifiant est renvoyé par Algolia (remoteIds), dans l'ordre de items.

Algolia n'AJOUTE que des correspondances (fautes de frappe, accents, ordre des mots) : il ne retire jamais un résultat local. Les identifiants inconnus de items sont ignorés, donc la liste reste bornée à ce qui est déjà chargé.

Implementation

List<T> unionVisible<T>({
  required List<T> items,
  required bool Function(T item) matchesLocally,
  required String? Function(T item) idOf,
  required Set<String> remoteIds,
}) => items
    .where((T item) {
      if (matchesLocally(item)) return true;
      final String? id = idOf(item);
      return id != null && remoteIds.contains(id);
    })
    .toList(growable: false);
