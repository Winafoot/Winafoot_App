MaintenanceGate

MaintenanceGate class

Écoute en temps réel app_config/metadata et bascule toute l'application :

  • sur MaintenanceRoute quand maintenance passe à true ;
  • sinon sur UpdateRequiredRoute quand le build installé est inférieur à minBuild de sa plateforme (voir AppUpdate) ;
  • de nouveau sur la route initiale quand plus rien ne bloque.

La bascule vaut aussi pour une app déjà ouverte. Le flag maintenance est posé par la cloud function onBudgetAlert (coupe-circuit budget) avant le détachement de la facturation : Firestore reste lisible en plan Spark, donc l'écran s'affiche même app « coupée ».
