Pose le nombre de joueurs puis enchaîne sur les numéros : d'abord la popup qui réserve des numéros aux remplaçants, puis l'écran « Attribuez les numéros ». La popup n'est ouverte QUE d'ici : un chemin qui saute le choix du nombre doit donc passer par cette fonction, sinon les remplaçants retombent en silence sur l'intervalle contigu (subNumbersOf).

Implementation

Future<void> continueWithPlayerCount(
  BuildContext context,
  WidgetRef ref,
  int count,
) async {
  ref.read(compositionDraftProvider.notifier).setCount(count);
  // « Popup qui arrive juste avant les interfaces (Gérer mon équipe step 2) »,
  // dit la maquette : le coach choisit d'abord quels numéros iront aux
  // remplaçants.
  await showSubNumbersDialog(context, ref);
  if (!context.mounted) return;
  await Navigator.of(context).push(
    MaterialPageRoute<void>(builder: (_) => const GererEquipeNumbersScreen()),
  );
}
