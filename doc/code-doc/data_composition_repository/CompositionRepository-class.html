CompositionRepository

CompositionRepository class abstract

Persistance des compositions personnalisées du coach, dans la sous-collection users/{uid}/compositions.

Les compositions standards restent des constantes de l'app (cf. formation.dart) ; seules les compositions « custom » créées par le coach sont stockées ici.
