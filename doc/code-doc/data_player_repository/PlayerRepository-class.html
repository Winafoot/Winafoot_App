PlayerRepository

PlayerRepository class abstract

Accès à l'effectif du coach connecté, stocké dans la sous-collection Firestore users/{uid}/players.

Un joueur n'est PAS un utilisateur : c'est une simple fiche (prénom, nom, pied fort, poste) rattachée au document de l'utilisateur courant.

addPlayer(Player player, {int? order}) → Future<void>
Ajoute un joueur (id auto-généré). order par défaut = nombre actuel.
configMaxSquadSize() → Future<int>
Plafond des comptes sans format de club, lu dans app_config/config.max_players. Repli sur kMaxSquadSize si le document, le champ ou le réseau manquent : mieux vaut le plafond historique qu'une création bloquée.
deletePlayer(String id) → Future<void>
Supprime définitivement un joueur, par le callable deletePlayer : le serveur recale aussi le compteur d'effectif, que le client ne peut plus écrire (les règles refusent la suppression directe).
maxSquadSize() → Future<int>
Plafond d'effectif de l'utilisateur connecté : celui de son format de club (users/{uid}.teamFormat) s'il est connu, sinon configMaxSquadSize.
updatePlayer(Player player) → Future<void>
Met à jour les champs éditables d'un joueur existant.
watchPlayers() → Stream<List<Player>>
Flux temps réel de l'effectif, ordonné par order (ordre d'affichage).
