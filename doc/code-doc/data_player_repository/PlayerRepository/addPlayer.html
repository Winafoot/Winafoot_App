Ajoute un joueur (id auto-généré). order par défaut = nombre actuel.

La création passe par le callable createPlayer : les règles Firestore refusent toute création directe, car elles ne savent pas compter les documents d'une collection (un client modifié contournait le compteur). Le serveur applique le plafond sur le nombre réel de joueurs (format du club, sinon app_config/config) et répond failed-precondition quand l'effectif est complet.

Lève une SquadFullException dans ce cas, pour afficher un message clair plutôt qu'une erreur réseau opaque.

Implementation

static Future<void> addPlayer(Player player, {int? order}) async {
  try {
    await _callable('createPlayer').call<dynamic>(<String, dynamic>{
      ...player.toJson(),
      if (order != null) 'order': order,
    });
  } on FirebaseFunctionsException catch (e) {
    if (e.code == 'failed-precondition') throw const SquadFullException();
    rethrow;
  }
}
