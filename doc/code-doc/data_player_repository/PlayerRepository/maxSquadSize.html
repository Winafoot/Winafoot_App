maxSquadSize static method

Future<int> maxSquadSize()

Plafond d'effectif de l'utilisateur connecté : celui de son format de club (users/{uid}.teamFormat) s'il est connu, sinon configMaxSquadSize.

Rien n'est mis en cache : le plafond dépend du compte, et un cache statique servirait au second compte connecté dans la session celui du premier. Une lecture illisible (hors ligne, pas de session) retombe sur le plafond historique, jamais sur celui d'un petit format.

Implementation

static Future<int> maxSquadSize() async {
  try {
    final DocumentSnapshot<Map<String, dynamic>> doc = await _userDoc().get();
    final PlayerCount? format = PlayerCount.fromValue(
      doc.data()?['teamFormat'],
    );
    if (format != null) return format.maxSquadSize;
  } catch (_) {
    // Repli ci-dessous.
  }
  return configMaxSquadSize();
}
