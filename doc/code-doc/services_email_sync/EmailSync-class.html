EmailSync

EmailSync class abstract final

Recopie dans users/{uid}.email l'adresse de Firebase Auth quand elle a changé.

Le changement d'adresse passe par verifyBeforeUpdateEmail : Firebase Auth ne bascule sur la nouvelle adresse qu'après le clic sur le lien reçu. Le document Firestore est donc mis à jour ensuite, au lancement, à chaque connexion et au retour de l'app au premier plan, à partir du compte rechargé.
